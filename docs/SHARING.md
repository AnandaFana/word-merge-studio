# 分享和获取源码

同事可以从 GitHub 仓库页面下载 ZIP 或克隆仓库。安装 Node.js 22.13+ 后，在 Windows 双击 `start.cmd`，其他系统执行 `npm ci` 和 `npm run dev`。首次运行下载依赖，后续文档处理在本机完成。

仓库包含合成示例。真实 Word、合并结果、QA 输出、依赖缓存和任何凭据均不应进入 Git；这些路径已经加入 `.gitignore`。

v0.4 启动后先显示主页。“对比合并”处理两份版本，“合并 Word”拼接分章，“按章节融合”组织结构相近的报告。右上角可以切换中文/English。同事可以直接体验各入口的虚构示例，或选择自己的文件。参见 [多章节指南](CHAPTERS.md) 和 [章节融合指南](SECTIONS.md)。

本项目以 MIT 许可公开分享。代码及原创样例可按许可证使用，第三方依赖保留各自许可。`tmp/` 与真实文档保持忽略；仅允许 `examples/public` 中明确列名的三份虚构 DOCX 进入 Git。提交前运行 `node scripts/check-public-files.mjs` 检查跟踪文件，不要使用强制添加绕过排除规则。

从 Git 更新已有副本：在项目目录执行 `git pull`，然后执行 `npm ci` 更新锁定依赖，再重新启动。不同电脑的文档和当前审阅选择不通过 Git 同步。

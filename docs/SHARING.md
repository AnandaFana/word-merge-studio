# 分享和获取源码

同事可以从 GitHub 仓库页面下载 ZIP 或克隆仓库。安装 Node.js 22.12+ 后，在 Windows 双击 `start.cmd`，其他系统执行 `npm ci` 和 `npm run dev`。首次运行下载依赖，后续文档处理在本机完成。

仓库包含合成示例。真实 Word、合并结果、QA 输出、依赖缓存和任何凭据均不应进入 Git；这些路径已经加入 `.gitignore`。

v0.3 启动后先显示主页。原来的功能在“对比合并”，多章节拼接与大纲统一在“合并 Word”。同事可以直接体验各入口的虚构示例，或选择自己的文件。分章操作说明见 [多章节指南](CHAPTERS.md)。

如果仓库设为私有，仓库所有者需要在 GitHub 的 Settings → Collaborators 中添加同事。不要为方便分享而上传账号密码或访问令牌。公开仓库可以直接发送仓库链接。

从 Git 更新已有副本：在项目目录执行 `git pull`，然后执行 `npm ci` 更新锁定依赖，再重新启动。不同电脑的文档和当前审阅选择不通过 Git 同步。
